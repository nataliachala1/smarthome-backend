## Contrato vigente

- Estructura: hogar → dispositivo. Se retiraron los archivos, providers y endpoints de zonas, así como sus relaciones Prisma.
- `POST /api/v1/homes/:homeId/devices`: OWNER activo de un hogar operativo. Body: `deviceTypeId` (UUID), `name` (1–100 caracteres después de trim), opcionales `manufacturerDeviceId`, `transportType` (`WIFI`/`BLUETOOTH`), `messagingProtocol` (`MQTT`).
- `GET /api/v1/homes/:homeId/devices`: OWNER, MEMBER y GUEST con membresía activa; devuelve dispositivos activos. MEMBER/GUEST requieren hogar operativo. Un hogar ajeno produce 403, incluso si está vacío.
- Registro inicial: `ACTIVE`, conectividad `OFFLINE`, `isOn=false`, potencia desconocida. `OFFLINE` sigue siendo un estado IoT.
- Respuesta: `id`, `homeId`, `deviceTypeId`, `name`, `status`, `connectivityStatus`, `isOn`, `currentPowerW`, `manufacturerDeviceId`, `transportType`, `messagingProtocol`, `createdAt`, `updatedAt`.
- Errores: 400 para UUID/body/tipo inválidos; 403 para falta de permisos; 409 para nombre activo o identificador de fabricante duplicado. JWT sigue siendo obligatorio.
- Swagger: `/api/docs`. No se encontró una colección Postman existente.

Se conserva autenticación, hogares, membresías, invitaciones, alertas/notificaciones automáticas y metadata de backups. El modo offline y la sincronización manual no forman parte del alcance vigente. MQTT, WebSocket, consumo y demás módulos pendientes quedan para las fases posteriores; no se añadieron dependencias.

## Validación

Ejecutado:

```powershell
npm.cmd ci --ignore-scripts --no-audit --no-fund
npx.cmd prisma validate --config prisma7.config.ts
npx.cmd prisma generate --config prisma7.config.ts
npm.cmd run build
npx.cmd tsc --noEmit
npm.cmd test -- --runInBand
```

La instalación usa el lockfile. `--ignore-scripts` evita el hook ajeno a la aplicación `prisma skills sync`; Prisma se genera explícitamente. Prisma requirió acceso autorizado a su caché fuera del workspace.

Pruebas HTTP reales de dispositivos (requieren la base aislada y fixture descritos en el repositorio de base de datos):

```powershell

npx.cmd jest --config test/jest-e2e.json --runInBand devices-scope

No pretende validar JWT ni MQTT.
